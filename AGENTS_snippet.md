## Figures (Stormy-drawing)

Every figure, plot, map or structure image in this project follows the `plotting` skill (`.agents/skills/plotting/SKILL.md`, from https://github.com/hydrogen1222/Stormy-drawing): one folder per figure under `figures/`, with the data copied in, a `plot.py` that redraws it, and a `README.md` recipe. Read that skill before drawing or redrawing any figure. Where other figure guidance in this project differs, the `plotting` skill wins.
